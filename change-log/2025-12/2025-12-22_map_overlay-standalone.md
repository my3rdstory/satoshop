## 배경
- 외부 사이트에 적용 가능한 순수 HTML/CSS/JS 오버레이 버전이 필요하며 http 링크도 허용해야 함.

## 변경 사항
- `map_overlay/` 폴더에 정적 `index.html`, `map-overlay.css`, `map-overlay.js`를 추가.
- http/https 링크 입력을 지원하고, 배경 사이트를 iframe으로 깐 뒤 맵을 오버레이.
- 링크 자동 감지 후 T(새 탭)/M(모달) 단축키로 열도록 로직 구성.
- 기존 맵 페이지의 링크 입력 라벨을 http/https로 수정.

## 영향
- 별도 서버 없이 정적 파일만으로 외부 사이트 위에 맵 오버레이를 사용할 수 있음.
- 브라우저 보안 정책상 외부 도메인은 링크 감지가 제한될 수 있음.

## 대장 수동 테스트 가이드
1. `map_overlay/index.html`을 열고 좌측 하단에 `http://` 또는 `https://` 링크를 입력 후 적용.
2. 캐릭터를 링크 요소 위로 이동해 링크 힌트가 표시되는지 확인.
3. `T`로 새 탭, `M`으로 모달이 열리는지 확인하고 `ESC`/닫기 버튼으로 종료.
