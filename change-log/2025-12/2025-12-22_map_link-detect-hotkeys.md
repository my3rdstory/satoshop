## 배경
- 링크 영역을 직접 편집하지 않고, 캐릭터 위치에서 링크를 감지해 단축키로 열고 싶음.
- 화면에 표시되는 안내는 최소화하고, 좌측 하단에 배경 링크 입력 UI만 유지해야 함.

## 변경 사항
- 맵 HUD/안내 패널을 제거하고 좌측 하단 링크 입력/상태 패널로 UI를 단순화.
- 캐릭터 위치에서 링크를 감지해 즉시 표시하고 T(새 탭)/M(모달) 단축키로 열 수 있도록 로직 추가.
- 배경 사이트를 입력하면 전체 화면 iframe으로 깔고, 맵을 오버레이하는 구조로 변경.
- README의 인터랙티브 맵 설명을 최신 동작으로 갱신.

## 영향
- 링크 감지가 즉시 이루어지고 단축키로 빠르게 링크를 열 수 있음.
- 외부 도메인은 브라우저 보안 정책상 링크 감지가 제한될 수 있음.

## 대장 수동 테스트 가이드
1. `/map/` 좌측 하단에 https 링크를 입력하고 적용.
2. 캐릭터를 링크 요소 위로 이동하면 링크가 표시되는지 확인.
3. `T`로 새 탭이 열리는지, `M`으로 모달이 열리는지 확인.
4. `ESC` 또는 닫기 버튼으로 모달을 종료할 수 있는지 확인.
